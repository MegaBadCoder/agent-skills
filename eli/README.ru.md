# `/eli5` · `/eli14` · `/eli-intern`

Часть [agents](../) — скиллы для vibe coding в Cursor, Claude Code и Codex.

[English](README.md) · **Русский**

> Три ступени одной лестницы. Когда объяснение не заходит, помогают обычно не дополнительные слова, а другой уровень.

---

## Проблема

Агент рассказывает, что он построил, вы киваете. Через неделю открываете файл и понимаете, что усвоили не код, а пересказ.

Причина почти всегда в несовпадении уровня. Объяснение опиралось на термины, которых у вас нет, либо на контекст **этого** репозитория, которого вам никто не давал. Переспрашиваешь — получаешь то же самое, только громче.

Эти три скилла выбирают ступень осознанно:

| Скилл | Предполагает | Чем жертвует |
|---|---|---|
| `/eli5` | ничего | всем жаргоном — одна бытовая аналогия, доведённая до конца |
| `/eli14` | общее любопытство | ничем техническим, но каждый термин разбирается при первом появлении |
| `/eli-intern` | навык программирования вообще | только контекстом проекта — механизм остаётся полным |

`eli-intern` — то, что нужно, когда вводишь человека в подсистему: он не упрощает, **как** всё работает, он упрощает лишь предположение о том, что вы уже знаете про этот репозиторий.

## Установка

```bash
npx skills add MegaBadCoder/agent-skills --skill eli5 --skill eli14 --skill eli-intern -g -a claude-code -a cursor -a codex -y
```

Либо поставить весь набор плагином для Claude Code — см. [корневой README](../README.md#install).

---

## Как пользоваться

```
/eli5 как middleware авторизации понимает, кто вошёл
/eli14 что на самом деле делает этот редьюсер
/eli-intern src/processing/
```

Срабатывают и без команды: «объясни как пятилетнему», «как для ребёнка», «объясни как школьнику», «как новому разработчику», «введи в контекст».

Переключение по ходу разговора — это и есть основной сценарий. Если один и тот же вопрос возвращается дважды, это сигнал сменить ступень, а не повторить сказанное: `eli5` дополнительно включается сам, когда человек второй раз говорит «не понимаю» про одно и то же.
